# 数治通一期实施步骤

本文档面向开发与实施人员，说明如何在本机或容器中把数治通一期（治理基础）跑起来，并完成验证。

> 约定：后端代码在 `backend/`，前端代码在 `frontend/`，文档在 `docs/`。本期后端、前端目录由其他同学负责，本说明只讲"怎么启动和验证"，不涉及代码实现。

---

## 1. 环境要求

| 组件 | 版本要求 | 说明 |
|---|---|---|
| Python | 3.12 | 后端运行环境 |
| Node.js | 20.x | 前端构建与开发环境 |
| pip | 最新 | Python 包管理 |
| npm | 随 Node 20 自带 | 前端包管理 |
| Docker / Docker Compose | 可选 | 一键启动方案需要 |
| 操作系统 | Linux / macOS / Windows(WSL2) | 均可 |

检查命令：

```bash
python3 --version   # 应为 Python 3.12.x
node --version      # 应为 v20.x
npm --version
docker --version    # 可选
```

## 2. 后端启动（FastAPI + SQLite）

```bash
cd ~/workspace/shuzhitong/backend

# 1. 创建虚拟环境
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动（开发模式，热重载）
uvicorn app.main:app --reload --port 8000
```

启动成功后：

- API 服务：http://localhost:8000
- 接口文档（Swagger）：http://localhost:8000/docs
- 健康检查：`curl http://localhost:8000/api/health`（如后端提供该端点）

说明：

- 后端使用 SQLite，数据库文件默认落在 `backend/data/`（或项目 `data/`）目录，首次启动自动建表并可加载种子数据；
- JWT 密钥通过环境变量 `JWT_SECRET` 注入，本地开发未设置时使用默认值（生产环境必须设置，见 §6 Docker Compose）。

## 3. 前端启动（Vue3 + Element Plus + ECharts）

```bash
cd ~/workspace/shuzhitong/frontend

# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev
```

启动成功后访问：http://localhost:8080

说明：

- 前端 dev 模式默认把 `/api` 请求代理到 `http://localhost:8000`（后端），无需额外配置跨域；
- 如需修改代理地址，查看 `frontend/vite.config.*` 中的 `server.proxy` 配置。

## 5. Docker Compose 一键启动

在项目根目录执行：

```bash
cd ~/workspace/shuzhitong
docker compose up --build -d
```

启动后：

- 前端：http://localhost:8080
- 后端 API：http://localhost:8000
- 接口文档：http://localhost:8000/docs

常用命令：

```bash
docker compose logs -f            # 查看日志
docker compose logs -f api        # 只看后端日志
docker compose down               # 停止并删除容器（数据卷保留）
docker compose down -v            # 停止并删除容器及数据卷（谨慎）
```

数据持久化：SQLite 数据文件挂载在宿主机的 `./data` 目录（见 `docker-compose.yml`），容器重建后数据不丢失。

## 8. 常见问题

**Q1：`pip install -r requirements.txt` 报错或很慢？**
A：检查 Python 版本是否为 3.12；国内网络可换源：`pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple`。

**Q2：`uvicorn` 启动后访问 8000 端口无响应？**
A：确认命令是在 `backend/` 目录下执行的，且 `app.main:app` 路径与代码结构一致；检查端口是否被占用：`lsof -i :8000`（或 `netstat -tlnp | grep 8000`）。

**Q3：前端 `npm install` 失败？**
A：确认 Node 为 20.x（`node --version`）；可删除 `node_modules` 与 `package-lock.json` 后重试；国内网络可配置 npm 镜像。

**Q4：前端页面报 API 404 / 跨域错误？**
A：先确认后端已启动且 `http://localhost:8000/docs` 可访问；再检查前端 `vite.config` 中的 `/api` 代理目标是否为 `http://localhost:8000`。

**Q5：Docker 启动后前端打不开？**
A：`docker compose logs -f` 看两容器是否都 healthy；确认宿主机 8080/8000 端口未被占用；首次 `build` 较慢，耐心等待。

**Q6：SQLite 数据库文件在哪里？如何重置？**
A：本地开发在 `backend/data/`（或项目根 `data/`）；Docker 部署在宿主机 `./data`。重置：停止服务后删除 `*.db` 文件再重启，会重建空库（种子数据按后端初始化逻辑加载）。

**Q7：JWT 登录后很快过期？**
A：检查 `JWT_SECRET` 在前后端/容器间是否一致；开发环境 token 有效期见后端配置，生产环境请设置合理的过期时间并妥善保管密钥。
